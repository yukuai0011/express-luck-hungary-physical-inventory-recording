# Express Luck Inventory (Flutter)

Offline-first inventory scanner app built with Flutter and Material Design.

It follows the original PoC flow:

- Recording profile is established by scanning 2 QR codes in any order:
  - API endpoint QR containing `{"apiEndpoint":"<https://...>"}`
  - Recording info QR containing `{"orderNo":"1234","recordingNo":1,"locationCode":"FG HU"}`
- The profile is saved locally (Hive) and used for submissions.
- Work section lets you scan or type the package number, set Package Intact, and adjust Quantity (disabled when intact).
- On Submit, an HTTP POST is sent to the endpoint. If offline or request fails, the payload is queued in an offline outbox for later sync.

## Features

- Offline storage using Hive (no server required)
- Sessions (e.g., daily/warehouse) to group entries
- Add entries with item code, location, quantity, and remarks
- Export a session to CSV into your documents folder and download CI artifacts
- Material 3 UI; works on Android and Windows desktop

## Project layout

- `lib/main.dart` – App entry, Profile(2x QR), Work (barcode scan), Outbox sync
- `pubspec.yaml` – Dependencies; platform folders are generated by CI

## Run locally

If you have Flutter installed:

```
flutter --version
flutter pub get
flutter create .   # generates android/windows/ios/macos/linux if missing
flutter run        # choose a device (Android emulator or Windows desktop)
```

Optional: build release locally

```
# Android APK (needs Android SDK)
flutter build apk --release

# Windows desktop
flutter config --enable-windows-desktop
flutter build windows --release
```

## GitHub Actions (CI)

Workflow file: `.github/workflows/flutter-build.yml`

- Triggers on all branches (`push` and `pull_request`)
- Builds:
  - Android APK on Ubuntu runner
  - Windows EXE on Windows runner
- Uploads build artifacts:
  - `app-release.apk`
  - `windows-exe/*.exe`

No secrets or signing keys are required; artifacts are unsigned (debug/release without signing) for easy distribution and testing.

## Data and privacy

- All data is stored locally on the device using Hive.
- No sensitive information is committed to this public repository.
- Camera scanning uses `mobile_scanner` on Android/iOS and `weebi_barcode_scanner` on Windows/macOS for full cross-platform camera support.

## Notes

- Windows and macOS camera scanning is now supported using the `weebi_barcode_scanner` package powered by YOLO object detection and ZXing decoding.
- Manual input/paste JSON fallback is still available on all platforms as an alternative to camera scanning.
